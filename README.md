# Cloud Career OS (2026–2030)

A local-first React + TypeScript dashboard for tracking cloud-infrastructure learning, engineering evidence, job applications, competencies, internships, and LinkedIn writing. Progress is stored in browser local storage; export backups regularly.

## Requirements

- Node.js 18 or newer (Node.js 20+ recommended)
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:3000`).

## Production build

```bash
npm run build
npm run preview
```

## Notes

- No paid APIs or server are required.
- Job entries and verification dates are starter data, not guarantees of current openings or eligibility. Re-check the employer's official posting before applying.
- Use the in-app backup feature to export/import your data. Clearing browser site data may delete local progress.
